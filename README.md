# hxyfront-62012 回潮检测与克重放行台

染整小样实验室的回潮检测与克重放行工作台，由原"纺织染整小样管理"页扩展而成。

## 业务规则（由规则引擎独立承载）

1. **一批一单**：同一面料批次同时只允许一张未结束检测单（检测中 / 待复核均算未结束）。
2. **齐全性**：烘干温度、烘干时长、烘箱编号、两次称重（另含烘前湿重、试样面积）齐全且为正数，才可结束检测。
3. **校准有效期**：天平校准过期（有效截止日期早于判定日）只进待复核，**不得放行克重**；有效期末日当天仍有效。
4. **偏差红线**：两次称重相对第一次的偏差 `> 0.5%` 只进待复核，**不得放行克重**；`≤ 0.5%` 时干重取两次均值。
5. **计算**：回潮率 =（湿重 − 干重均值）÷ 干重均值 × 100%；放行克重 = 干重均值 ÷ 试样面积（g/m²）。
6. **更正失效重算**：更正烘干记录 → 该单原结论立即失效并重算；更正天平校准 → 使用该天平的全部已结束单据联动失效重算；旧结论、旧校准记录全部留档可查。
7. **幂等**：重复或并发提交沿用首次结果，不重复计算、不改变首次结论。
8. **刷新一致**：批次、复核队列、检测履历由同一 localStorage 记录存储驱动；刷新时按当前规则复核已生效结论，不一致即失效重算。

## 架构（规则 / 记录 / 页面分离）

```
src/
  rules/            # 纯规则层（无 React、无存储）
    types.ts        # 领域模型
    engine.ts       # 齐全性、校准有效期、0.5% 偏差、回潮/克重计算、判定
  data/             # 记录层（localStorage + 状态订阅）
    seed.ts         # 演示数据：检测中 / 已放行 / 偏差超限复核 / 校准过期复核
    station.ts      # 开单、提交、更正烘干、更正校准、复核意见、刷新重算、幂等
    useStation.ts   # React 订阅绑定
  components/       # 页面层
    BatchPanel      # 批次列表、新建批次/检测单
    SheetPanel      # 烘干记录、两次称重、天平、实时规则预览、提交/更正、旧结论留档
    ReviewQueue     # 待复核队列、复核意见登记
    BalancePanel    # 天平校准档案与更正（联动重算）
    HistoryPanel    # 检测履历（含已失效留档行、批次筛选）
    RulePanel       # 规则文本承载
```
